# husanisomiddinov.com

Personal website — books, essays, projects, and studio. Built with Next.js
(App Router), TypeScript, Tailwind CSS, and MDX content. Deployed on Vercel.

Rebuilt from a prior Next.js Pages Router + Chakra UI version — same visual
design, modernized implementation (React Server Components, Tailwind instead
of runtime CSS-in-JS, a cleaned-up content pipeline).

## Requirements

- Node.js >= 20.9.0
- Yarn (v1)

## Getting started

```bash
yarn install
cp .env.local.example .env.local   # optional; site runs without it
yarn dev                           # http://localhost:3000
```

## Scripts

| Script          | Description                                              |
| --------------- | ---------------------------------------------------------|
| `yarn dev`      | Generate content index, then start the dev server        |
| `yarn build`    | Generate content index, then build for production        |
| `yarn start`    | Serve the production build                                |
| `yarn lint`     | ESLint (Next core-web-vitals + jsx-a11y), zero warnings   |
| `yarn generate` | Build `content/books/index.json` from the MDX book files  |

The sitemap is generated natively by `src/app/sitemap.ts` — no separate script.

## Content

- `content/books/*.mdx` — book notes; the build derives `index.json` from these (gitignored, regenerated by `yarn generate`).
- `content/writing/*.mdx` — essays and notes (frontmatter: `title`, `date`, `cover?`, `tag?`).
- `content/data/**/*.json` — structured data (projects, quotes, facts, arsenal, etc.).
- `content/pages/*.mdx` — home and about page copy.

MDX is compiled server-side via `next-mdx-remote/rsc`; frontmatter parsing
uses `gray-matter`.

## Environment variables

All optional — see `.env.local.example`. Without them the site still builds;
analytics are disabled and the site URL falls back to the production domain.

| Variable                       | Purpose                                           |
| ------------------------------ | ------------------------------------------------- |
| `NEXT_PUBLIC_SITE_URL`         | Canonical URL for SEO, Open Graph, and the sitemap |
| `NEXT_PUBLIC_GA_ID`            | Google Analytics measurement ID                    |
| `NEXT_PUBLIC_POSTHOG_API_KEY`  | PostHog project key for product analytics          |
